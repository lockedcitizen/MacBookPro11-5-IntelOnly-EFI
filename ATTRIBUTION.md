# Attribution

This is an independent development effort for MacBookPro11,5.

References informing the hardware research and validation plan:

- **bbatchelder/macbookpro11-5-intel-efi** — model-specific EFI helper and
  documented Intel internal-panel handoff:
  https://github.com/bbatchelder/macbookpro11-5-intel-efi
- **0xbb/apple_set_os.efi** — Apple's Set OS protocol helper:
  https://github.com/0xbb/apple_set_os.efi
- **Linux kernel apple-gmux driver** — GMUX behavior reference:
  https://github.com/torvalds/linux

No upstream implementation source is copied into this initial scaffold.
Any future code adapted from GPL-licensed upstream files must retain required
copyright notices and compatible GPL licensing. MIT-derived portions must
retain their MIT notice.
